This script guides evaluators through the complete prototype workflow in under 5 minutes.

## 🧭 The 6-Step Judge Journey

### Step 1: Public Landing Page & Instant Demo Launch
1. Open the live site: `https://azzu1930.github.io/skillbridge-ai/`
2. Point out the clear problem definition: Student Skill Gap vs Industry Talent Gap.
3. Click the prominent **"Launch Demo"** or select **"Student Demo"** card (Abdul Aziz, Backend Track).

### Step 2: AI Student Skill Twin (`/student/skill-twin`)
1. Show the dynamic radar polygon and competency scores: Python 87%, SQL 78%, Git 72%.
2. Click any skill card (e.g. **Python** or **SQL**) to inspect verifiable evidence proofs: GitHub repo commits, assessment tests, and verified courses.
3. Emphasize: *Skills are calculated from verified evidence, not unverified resume claims.*

### Step 3: AI Skill Gap Analysis (`/student/skill-gap`)
1. Demonstrate target role selection: **Backend Developer**.
2. Point out the calculated 68% Match.
3. Show the exact breakdown: Python ✓, SQL ✓, but FastAPI ✗, Docker ✗, Cloud ✗.
4. Review the qualitative explanation: *Why does industry expect FastAPI and Docker for microservices?*

### Step 4: The Killer Demo — Career Readiness Simulator (`/student/simulator`)
1. Highlight baseline readiness: **68%**.
2. Check off **"Learn REST APIs (+4%)"** $\to$ Watch projection climb to **72%**.
3. Check off **"Master FastAPI (+5%)"** $\to$ Watch projection climb to **77%**.
4. Check off **"Build Backend Project (+7%)"** $\to$ Projection reaches **84%**!
5. Highlight the **"Recommended Fastest Path"** algorithm ranking skills by ROI (Impact per week).
6. Note the clear disclaimer: *Model-based readiness projection (not guaranteed employment probability).*

### Step 5: Opportunity Matching & Apply (`/student/opportunities`)
1. Browse opportunities: Show **Backend Developer Intern @ Razorpay (92% Match)**.
2. Click **"Apply Now"** $\to$ Observe live submission confirmation.
3. Navigate to **Applications Tracker (`/student/applications`)** and view the application in the Kanban board.

### Step 6: Switch to Industry & Closed-Loop Academia (`/industry/candidates` & `/admin/intelligence`)
1. Use the top Navbar role switcher to toggle into **Industry Mode**.
2. Open **AI Candidate Matcher (`/industry/candidates`)**:
   - Show ranked candidates (Abdul Aziz ranked #1 at 94% fit).
   - Click **"Why this candidate?"** to demonstrate the transparent natural-language explainability modal.
3. Switch into **Admin Mode** $\to$ Open **Closed-Loop Intelligence (`/admin/intelligence`)**:
   - Show how Razorpay's feedback on cohort deficits (61% Cloud deficit) directly connects to Step 3.
   - Click **"Generate Training Plan"** in the Training Engine (`/admin/training`) to observe automated institutional remediation (+12 readiness boost).
